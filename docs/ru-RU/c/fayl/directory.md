# Каталог
Небольшая динамически изменяемая коллекция, предназначенная для представления элементов, содержащихся в директории файловой системы.

### Конструирование
Для создания новой директории определены две функции: `directory_init` и `directory_init_with_capacity`. Названия этих функций говорят сами за себя.
Разница между ними заключается в том, что `directory_init` создаёт новую директорию с заранее определённой ёмкостью, тогда как `directory_init_with_capacity` позволяет явно указать её.
Если какая-либо из этих функций конструирования завершается неудачей, библиотека паникует с `AllocationError`.

### Добавление
Для добавления `entry_t` в директорию определена очевидно названная функция `directory_append`.
Эта функция может завершиться с ошибкой `AllocationError`.

#### Владение
Что касается владения внутренним массивом директории: все элементы, добавленные в директорию, должны принадлежать директории.
Любой элемент, добавленный в директорию, &mdash; особенно удалённый элемент &mdash; будет иметь все свои поля уничтоженными при вызове функции `directory_delete`.

### Доступ
Чтобы доступить к элементу внутри директории определена функция `directory_at`.
Эта функция принимает индекс и возвращает `entry_t`, хранящийся в директории по указанному индексу. Если переданный индекс находится за пределами директории, программа паникует с `IndexError`.

### Удаление
Чтобы удалить элемента из директории определена функция `directory_remove`.
Эта функция принимает индекс и удаляет `entry_t`, хранящийся в директории по указанному индексу. Если переданный индекс находится за пределами директории, программа паникует с `IndexError`.
Эта функция не изменяет `capacity`.
Удалённый `entry_t`, ранее находившийся по указанному индексу, теряет все свои поля при удалении из директории.

### Освобождение
Поскольку это классический динамический массив, память, выделенная под директорию, должна быть освобождена.
Чтобы освобождать директории определена функция `directory_delete`. Эта функция освобождает как внутренний массив директории, так и все хранящиеся или выделенные свойства каждого из содержащихся в нём элементов.
