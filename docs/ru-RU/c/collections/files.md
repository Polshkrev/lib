# Файлы

Temu-обходчик файлов.

Другими словами, небольшой динамический список для хранения путей к файлам, обнаруженных внутри директории файловой системы.
Список владеет памятью, выделенной для каждого сохранённого пути, в то время как сам `root` не является владеющим указателем. В текущей реализации поддерживается только `Windows`, а обход дерева директорий выполняется рекурсивно, начиная с указанного `root`.
По умолчанию список инициализируется с вместимостью в `256` элементов. Это значение можно изменить, определив `FILES_CAPACITY` перед подключением реализации.

## Использование
Предполагаемый сценарий использования заключается в создании списка с указанием корневой директории, заполнении его элементами, содержащимися внутри директории.

### Создание
Чтобы созданить нового списка файлов предназначена функция `files_init`. Она инициализирует список с вместимостью по умолчанию, заданной через `FILES_CAPACITY`.
Чтобы получить большего контроля над начальным выделением памяти можно использовать `files_init_with_capacity`, передав необходимую вместимость:
```c
files_t files = files_init_with_capacity("C:\\Projects", 512);
```
Переданный в любую из этих функций `root` сохраняется напрямую и не копируется. Поэтому вызывающая сторона должна гарантировать, что строка остаётся действительной на протяжении всего времени существования списка.

### Изменение
Чтобы добавленить пути к списку определена функция `files_append`.
Как и в стандартном динамическом списке, если список заполняется, функция `files_resize` удваивает емкость списка, а функция `files_resize_by` позволяет увеличить емкость на заданный масштабирующий коэффициент:
```c
void files_append(files_t *files, const char *entry)
{
    if (files->size >= files->capacity)
    {
        files_resize(files); // files_resize_by(&files, 2);
    }
    /* ... */
}
```
Чтобы обеспеченить соответствия емкости текущему количеству сохраненных путей определена функция `files_fit`.

### Доступ
Чтобы получить пути по определённому индексу предназначена функция `files_at`. Она возвращает указатель на сохранённый путь, если индекс является допустимым, и `NULL`, если индекс выходит за пределы текущего размера списка.
Например:
```c
char **path = files_at(&files, 0);
```

### Заполнение
Чтобы заполненить списка содержимым корневой директории предназначена функция `files_fill`.
В `Windows` функция рекурсивно обходит директорию, начиная с `root`, добавляя каждый обнаруженный элемент в список. Директории обходятся рекурсивно, поэтому пути, находящиеся во вложенных директориях, также добавляются в список.
Функция возвращает `true`, если дерево директорий удалось успешно обойти, и `false`, если не удалось получить какой-либо элемент.

### Память
Список владеет памятью, выделенной для хранящихся в нём путей. Чтобы освобожденить этой памяти предназначена функция `files_delete`.
`files_delete` освобождает каждый путь, сохранённый в списке, после чего освобождает сам список указателей.
Указатель `root` не освобождается, поскольку список не владеет памятью, на которую он указывает.
