# Строка

Эта библиотека вдохновлена библиотекой [string view от Tsoding](https://github.com/tsoding/sv).

Это структурированный, не завершаемый нулевым байтом и практически радиоактивно ограниченный по размеру строковый тип. Хотя выделение структуры в куче само по себе не является чем-то неслыханным, по своей природе это представление (view), поэтому указатель на исходные данные не является владеющим. Структура не требует выделения памяти в куче или её освобождения.

Библиотека также предоставляет базовую поддержку UTF-8.

## Использование
Чтобы сохранить простоту этого модуля, на момент написания ни одна из определённых в нём функций не завершается ошибкой.

### Создание
Существует несколько способов создать строковое представление.
`string_new()` создаёт строковое представление из указателя и явно указанного количества байт:
```c
string_t string = string_new("Hello World", 11);
```
`static_string_new()` может определить размер строкового литерала или массива символов во время компиляции.
Ему нельзя передавать переменную-указатель, поскольку `sizeof()` вернёт размер указателя, а не размер строки.
Для null-terminated C-строк используйте `string_from()`.
В отличие от `static_string_new()`, `string_from()` принимает любую null-terminated C-строку.
Пустую строку можно представить с помощью `string_null`.
Пустая строка и null-строка — это разные понятия. Пустая строка имеет `count`, равный нулю, тогда как null-строка имеет одновременно нулевой `count` и указатель `data`, равный `NULL`.

### Изменение
Само строковое представление можно изменять, не изменяя исходные символьные данные.
`string_trim_left()`, `string_trim_right()` и `string_trim()` удаляют пробельные символы в начале, в конце или с обеих сторон строки соответственно.
Эти функции изменяют только указатель и значение `count`, хранящиеся в `string_t`.
`string_chop_by_delimiter()` разделяет строковое представление по первому найденному разделителю. Возвращаемое представление содержит всё, что находится перед разделителем, а исходное представление перемещается за него.
Если разделитель не найден, возвращаемое представление содержит всю строку, а исходное представление становится пустым.

### Доступ
Доступ к исходным данным осуществляется через `data`, а к их размеру — через `count`. Для вывода строки сначала необходимо использовать макрос `string_format`, а для передачи форматируемой строки — вызвать макрос `string_argument`:
```c
printf(string_format"\n", string_argument(string));
```
Функции `string_find_first_of()` и `string_find_last_of()` выполняют поиск байта и возвращают его индекс в байтах.
Если байт не найден, возвращается `STRING_NOT_FOUND`.
Эти функции работают с байтами и не выполняют поиск Unicode-кодовых точек.

Библиотека также предоставляет:
- `string_starts_with()` — проверяет наличие префикса.
- `string_ends_with()` — проверяет наличие суффикса.
- `string_equals()` — выполняет регистрозависимое сравнение.
- `string_is_empty()` — проверяет, равен ли `count` нулю.
- `string_is_null()` — проверяет наличие `NULL` в `data` при нулевом `count`.

Все эти операции работают с байтами.

### UTF-8
Библиотека предоставляет проверку корректности UTF-8 и подсчёт количества кодовых точек.
`string_is_valid_utf8()` определяет, содержит ли строка корректный UTF-8.
`string_utf8_length()` возвращает количество Unicode-кодовых точек, представленных строкой.
Важно различать:
```text
string.count          -> количество байт
string_utf8_length()  -> количество Unicode-кодовых точек
```
Например, `Привет` содержит 12 байт, но всего 6 кодовых точек.

Проверка UTF-8 отклоняет:
- Некорректные байты продолжения.
- Избыточные (overlong) кодировки.
- Кодовые точки суррогатов UTF-16.
- Кодовые точки выше `U+10FFFF`.
- Усечённые последовательности.

`UTF-8`-длина считает кодовые точки, а не воспринимаемые пользователем символы. Поэтому комбинируемые диакритические знаки могут учитываться как отдельные кодовые точки.
Обычные функции поиска и сравнения по-прежнему работают с байтами. Это сделано намеренно.
При необходимости можно выполнять проверки Unicode, не усложняя каждую операцию над строками.
