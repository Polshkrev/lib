# Буфер
Временный распределитель памяти, созданный по образцу [временного распределителя памяти Tsoding-а](https://github.com/tsoding/nob.h/blob/main/nob.h#L604).

Буфер предоставляет простой способ выполнять временные выделения памяти без постоянного выделения и освобождения памяти в куче. Все выделения выполняются из буфера фиксированного размера и становятся недействительными после сброса или перемотки буфера.

По умолчанию буфер имеет размер 5 KiB. Его размер можно изменить, определив `TEMP_CAPACITY` перед подключением реализации.

## Использование
Буфер в первую очередь предназначен для временных выделений памяти, сроком жизни которых можно управлять совместно, вместо индивидуального управления каждым выделением. В отличие от обычного выделения памяти в куче, для отдельных выделений не существует соответствующей операции освобождения.

Когда в буфере заканчивается свободное место, `buffer_allocate` возвращает `NULL`, тогда как строковые функции выводят `AllocationError` в `stderr` и завершают выполнение программы.

### Выделение
Чтобы выделенить памяти из буфера определена функция `buffer_allocate`. Она принимает количество байт для выделения и возвращает указатель на выделенную область памяти.

Возвращённая память принадлежит буферу и не должна освобождаться вручную. После перемотки или сброса буфера ранее выделенная память должна считаться недействительной.

### Строки
Чтобы работать со строками определены две вспомогательные функции.

Функция `buffer_duplicate` копирует строку с завершающим нулём в буфер и возвращает указатель на её новую копию. Полученная строка также завершается нулём и поэтому может использоваться везде, где ожидается обычная C-строка.

Функция `buffer_sprintf` предоставляет интерфейс в стиле `printf` для создания форматированной строки непосредственно внутри буфера. Например:

```c
char *message = buffer_sprintf("Hello, %s!", "World");
```

Обе функции завершают выполнение программы, если в буфере недостаточно места для запрашиваемой строки.

### Контрольные точки
Буфер поддерживает контрольные точки с помощью функций `buffer_save` и `buffer_rewind`.

`buffer_save` возвращает текущую позицию курсора буфера. Это значение впоследствии можно передать в `buffer_rewind`, чтобы удалить всё, что было выделено после создания контрольной точки.

Таким образом, часть буфера можно использовать как временную область выделения:

```c
size_t checkpoint = buffer_save();

char *message = buffer_sprintf("Hello, World!");

buffer_rewind(checkpoint);
```

После перемотки память, занимаемая `message`, снова становится доступной для последующих выделений.

### Сброс
Чтобы сбросить буфера в полне, определена функция `buffer_reset`. Она перемещает курсор буфера обратно в начало, тем самым снова делая весь буфер доступным для выделения.

Содержимое буфера при этом явно не стирается; оно просто считается неиспользуемым.
