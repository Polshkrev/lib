### Конструирование
Для создания новой директории определено несколько перегрузок конструктора. Важно отметить, что любая из перегрузок конструктора может выбросить `AllocationError`.
Определён конструктор `default`. Он создаёт директорию с `current directory` в качестве корневой директории.
Также определены ещё две перегрузки: перегрузка, принимающая `path_t` в качестве корневого пути, и перегрузка, принимающая `capacity`.
Как и в [реализации на C](/docs/ru-RU/c/fayl/directory.md), каждый `entry_t`, хранящийся внутри директории, является принадлежащим ей значением, срок жизни которого совпадает со сроком жизни самой директории.
Если любая из этих перегрузок конструктора завершается неудачей, библиотека выбрасывает `AllocationError`.

### Добавление
Чтобы добавить `entry_t` в директорию определена очевидно названная функция `directory_append`.
Эта функция может завершиться с ошибкой `AllocationError`.

#### Владение
Стоит отдельно отметить модель владения внутренним массивом директории: все элементы, добавленные в директорию, должны принадлежать директории, как было упомянуто ранее.
Любой элемент, добавленный в директорию, &mdash; особенно `removed`-элемент &mdash; будет иметь все свои поля уничтоженными при вызове `destructor` директории.

### Доступ
Чтобы доступить к элементу внутри директории определена функция `directory_at`.
Эта функция принимает индекс и возвращает `entry_t`, хранящийся в директории по указанному индексу. Если переданный индекс находится за пределами директории, программа паникует с `IndexError`.

### Удаление
Чтобы удалить элемента из директории определена функция `directory_remove`.
Эта функция принимает индекс и удаляет `entry_t`, хранящийся в директории по указанному индексу. Если переданный индекс находится за пределами директории, программа паникует с `IndexError`.
Этот деструктор освобождает как внутренний массив директории, так и все хранящиеся или выделенные свойства каждого содержащегося в нём элемента.
