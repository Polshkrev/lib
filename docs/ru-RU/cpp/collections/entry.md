# Запись
Представление записи файловой системы на C++. Запись может представлять файл, каталог или неопределённую запись файловой системы.

## Использование
### Создание
Запись можно создать с указанием пути, типа или обоих параметров. Если тип не указан, записи присваивается значение `type_t::NONE`.
```cpp

polutils::fayl::entry_t file(polutils::fayl::path_t("example.txt"), polutils::fayl::type_t::FILE);

```

### Создание файловой системы
`touch()` создаёт файл по пути, указанному в записи. Запись должна иметь тип `type_t::FILE`.
`mkdir()` создаёт каталог по пути, указанному в записи. Запись должна иметь тип `type_t::DIRECTORY`.
Обе функции выбрасывают `FileExistsError`, если целевой объект уже существует, и `IOError`, если операция завершается с ошибкой.

### Чтение и запись
`read()` считывает содержимое файла по пути, указанному в записи, во внутреннее содержимое записи.
`write()` записывает содержимое по указанному пути. Она может записать явно переданное содержимое по пути записи или сохранённое в записи содержимое по другому пути.
Запись можно удалить из файловой системы с помощью `remove()`. Запись должна представлять файл.

### Перемещение и копирование
`move()` перемещает файл по пути записи в путь другой записи.
`copy()` копирует файл в другую запись. 
Исходная и целевая записи должны иметь тип `type_t::FILE`.

### Доступ
Запись предоставляет доступ к своему пути, типу и сохранённому содержимому с помощью `path()`, `type()` и `content()`.
Эти свойства можно изменить с помощью `set_path()`, `set_type()` и `set_content()`.
`is()` можно использовать для определения того, имеет ли запись определённый тип.
`size()` возвращает размер файла в байтах, а `is_empty()` определяет, не содержит ли файл содержимого.
`to_string()` возвращает строковое представление записи.

## Типы
Перечисление `type_t` определяет тип записи.
| Тип                  | Описание                        |
| -------------------- | ------------------------------- |
| `type_t::NONE`       | Тип не указан.                  |
| `type_t::DIRECTORY`  | Запись представляет каталог.    |
| `type_t::FILE`       | Запись представляет файл.       |

`type_to_string()` преобразует тип записи в его строковое представление.
