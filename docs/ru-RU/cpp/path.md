# Адрес
Реализация на C++, вдохновлённая [Python's `pathlib`](https://docs.python.org/3/library/pathlib.html).
Тип `path_t` представляет путь в файловой системе и предоставляет операции для его создания, изменения и получения информации о нём.
`path_t` наследуется от `printable_t`, предоставляя общий интерфейс для получения строкового представления пути через `to_string()`.

## Использование
### Создание
Чтобы созданить нового объекта пути доступны две перегрузки конструктора. Конструктор по умолчанию создаёт путь, представляющий текущий рабочий каталог, тогда как другой конструктор принимает строку, представляющую путь.

### Изменение
Чтобы изменить пути оператор `/` перегружен для добавления другого пути к текущему пути. Он принимает другой объект пути или строку. Оператор возвращает новый путь, не изменяя исходный.

### Получение информации
Путь можно использовать для получения информации о его свойствах и компонентах. Библиотека предоставляет операции для проверки существования пути, получения его абсолютного пути, родительского и корневого путей, а также доступа к его `filename` и `extension`.
Операция `filename` возвращает последний компонент пути без его расширения, тогда как `extension` возвращает расширение файла, например `c`, `h`, `md` и так далее.
Операция `to_string` предоставляет доступ к пути в виде C-строки с завершающим нулевым символом через интерфейс `printable_t`.
